A Mac you can describe in one file, and rebuild from it on any machine you
own. Two things are documented here: the layer that makes that true, and the
desktop somebody already built with it.

<Cards>
  <Card

  />
  <Card
    icon={<Icon name="desktop" />}
    title="nebelhaus"
    href="/docs/nebelhaus"
    description="A desktop built on it. Silver-grey, keyboard-first, tiling, and the same on the next machine. One command from a stock Mac."
  />
</Cards>

**haus** is the machinery; **nebelhaus** is one thing made with it. Installing
the desktop installs the layer underneath, so if you only want the finished
room, start on the right.

The switcher at the top of the sidebar moves between the two, and its glyph
tells you which one you're reading at a glance: <Icon name="layer" /> the
layer, <Icon name="desktop" /> the desktop.

Reading this with an AI tool? These docs publish themselves in machine-readable
form: [`/llms.txt`](/llms.txt) is a table of contents with one-line
descriptions, for something that fetches selectively, and
[`/llms-full.txt`](/llms-full.txt) is every page inlined, for something that
would rather read the lot. On a machine that already has haus, prefer the `haus`
skill — it is generated from the revision you actually run.
[Changing your Mac with an agent](/docs/haus/rooms/agent-rebuilds) covers it.
