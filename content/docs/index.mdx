A Mac you can describe in one file, and rebuild from it on any machine you own —
and the small native tools that live inside it. Two things are documented here:
the layer, and the app.

**haus** is the machinery; **pounce** is one of the things that runs on it — and
runs perfectly well on a Mac that has never heard of it. Installing haus can
install pounce for you; installing pounce needs nothing but Homebrew.

The switcher at the top of the sidebar moves between the two, and its glyph
tells you which one you're reading at a glance: <Icon name="layer" /> the
layer, <Icon name="pounce" /> the launcher.

Looking for a **desktop** — nebelhaus and the rest? A desktop is a set of
values for haus's own options rather than a project of its own, so it is
documented with the layer: [choosing one](/docs/haus/desktops/choosing) covers
what each turns on, and [nebelhaus](/desktops/nebelhaus) has a page of its own.

Reading this with an AI tool? These docs publish themselves in machine-readable
form: [`/llms.txt`](/llms.txt) is a table of contents with one-line
descriptions, for something that fetches selectively, and
[`/llms-full.txt`](/llms-full.txt) is every page inlined, for something that
would rather read the lot. On a machine that already has haus, prefer the `haus`
skill — it is generated from the revision you actually run.
[Changing your Mac with an agent](/docs/haus/rooms/agent-rebuilds) covers it.
