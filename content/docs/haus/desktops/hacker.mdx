**hacker** is a Mac arranged like a tiling Linux rig, but native to the grain
of the Mac: fog-grey, keyboard-first, and the same after you wipe the machine.
It is the desktop you get if you don't pick one.

You never edit the desktop to use it: the installer scaffolds a thin config of
your own at `~/.config/nix` that consumes it as an input, so your machine stays
yours and haus stays upstream.

```sh
curl -fsSL https://hausfold.co/hacker.sh | bash
```

That URL picks this desktop, so the installer skips the question.
[Install](/docs/haus/install) has the rest.

## What it turns on

Nearly every [room](/docs/haus): [Windows](/docs/haus/rooms/windows),
[Bar](/docs/haus/rooms/bar), [Launcher](/docs/haus/rooms/launcher),
[Shelf](/docs/haus/rooms/shelf), [Development](/docs/haus/rooms/development),
[Focus](/docs/haus/rooms/focus), [Security](/docs/haus/rooms/security),
[AI](/docs/haus/rooms/ai) and [Appearance](/docs/haus/rooms/appearance). Each
has its own switch, so anything it chose you override in a line: [Customize a
desktop](/docs/haus/desktops/customizing).

## First moves

The first switch has finished. Windows tile themselves, the menu bar has been
replaced, ⌘Space belongs to the palette, and `haus` is on your `PATH`. Here's
the muscle memory.

| Keys | What happens |
|---|---|
| **⌘Space** | The palette. Type a few letters, hit Return. Start here for everything |
| **Tap ⇪, then a letter** | Launch or focus that app. `T` is the terminal, `B` the browser |
| **Tap ⇪, then an arrow** | Move focus between tiled windows. Keep arrowing; hold ⇧ to *move* the window instead |
| **Tap ⇪, then a digit** | Jump to that workspace. Add ⇧ to throw the current window there and follow it, ⌥⇧ to send it and stay |
| **Tap ⇪, then /** | The cheatsheet, generated from *your* app list, so it is never out of date |

<Callout title="Tap Caps-Lock, don't hold it">
It's a leader key now, not a modifier. Tap and release, then press the letter.
</Callout>

Try these in order: **⇪ T** opens the terminal and tiles it; **⌘Space**, `saf`,
Return launches Safari; **⇪ ← / →** jumps focus between the two; **⌥/** flips
the split between horizontal and vertical; **⌘Space**, `emoji`, Return turns the
palette into an emoji grid.

One permission to grant: a few palette features use a keyboard path macOS gates
behind Accessibility. Everything else works without it.

```sh
pounce --request-accessibility
```

The rest live where they're configured: [Keys](/docs/haus/rooms/keys) has the
leader and every workspace throw, [Windows](/docs/haus/rooms/windows) the tiling
they drive, [Development](/docs/haus/rooms/development) the terminal's chords and
[pounce](/docs/pounce/using) the palette. Your own machine's copy (tap **⇪ /**)
is generated from your tables, so trust it when they disagree.

## Making it yours

Your settings live in one file, and `haus edit` opens it. The tweaks people
reach for first: an accent (`haus.theme.accent`), an editor
(`haus.terminal.editorName`, named so haus installs it), an app with a launcher
key and a workspace of its own (`haus.roster`, `haus.workspaces`). Then
`haus rebuild`. [Customize a desktop](/docs/haus/desktops/customizing) is the
rest of what that file can say, and [the haus
reference](/docs/haus/reference/haus) every command the CLI has.
