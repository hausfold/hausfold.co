**everyday** is the same care, aimed at a machine that will never open a
terminal. A quiet [bar](/docs/haus/rooms/bar) with the clock, the battery and
the weather: a better menu bar, not a new one. A
[search box](/docs/haus/rooms/launcher) on ⌘Space that opens anything. And
**none of the developer tooling**: no compilers, no agents, nothing installed
for a job this Mac isn't doing.

The rest is quieter. A [notch shelf](/docs/haus/rooms/shelf) for files on their
way somewhere else, one key to [go quiet](/docs/haus/rooms/focus) and one to
come back, [Touch ID](/docs/haus/rooms/security) instead of a password for
`sudo` with the rebuild included, so updating never stops to ask, the haus mark
on your palette as [a wallpaper](/docs/haus/rooms/appearance) with apps themed
to agree with it, and a tour that is one prompt, once: press ⌘Space, type, hit
Return.

It is a whole answer, not a stripped-down one.

```sh
curl -fsSL https://hausfold.co/everyday.sh | bash
```

The URL picks the desktop, so the installer won't ask.
[Install](/docs/haus/install) has the rest.

<Callout title="It needs an admin account, and the first setup takes a while">
Not a five-second install: it asks for your password once, downloads a few GB,
and sets things up so it doesn't have to ask again. Doing it for someone else?
Sit next to them.
</Callout>

## The judgement calls

A desktop is a set of decisions somebody made on your behalf. Two of them are
worth seeing before you install it, and both are one line in your own file
away.

**Tiling is off.** Tiling is good; remapping Caps-Lock to a leader key on
someone else's Mac is not. Windows keep the behaviour they already know,
because the fastest way to lose someone is to change what their machine does
when they click, and it is why this desktop claims no leader key at all.

**Developer tooling is off, and agents with it.** Coding agents on a machine
that ships no coding tools is a room enabling itself for nobody. If you want
them, `haus.ai.enable = true` is the line.

<Callout title="If you used the old everyday preset">
Same idea, built as a whole desktop rather than a layer over another one. Two
things a layered preset inherited are deliberately off: the coding agents, and
the Node toolchain that came with them.
[`desktops/everyday.nix`](https://github.com/hausfold/haus/blob/main/desktops/everyday.nix)
states every difference in full.
</Callout>
