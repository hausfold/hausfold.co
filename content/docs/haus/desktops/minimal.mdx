**minimal** is the terminal, finished, on an otherwise **stock macOS**. No bar,
no tiling, no launcher, no shelf: nothing that changes how the Mac behaves
outside the window you type in.

It is still a developer machine. Minimal here means **few rooms, not few
tools**, and the toolbelt is the same one hacker ships. A Mac with no developer
tooling at all is [everyday](/docs/haus/desktops/everyday).

```sh
curl -fsSL https://hausfold.co/minimal.sh | bash
```

The URL picks the desktop, so the installer won't ask; or, once Nix is
installed, `nix run github:hausfold/haus#bootstrap` straight from the flake.
[Install](/docs/haus/install) has the rest.

## What's in it

Two rooms, and the same modules hacker uses: fewer of them, not lesser ones.
[Development](/docs/haus/rooms/development) brings zsh, a tinted starship
prompt, git, Zed, the toolbelt with Node wired up, and a terminal whose windows
outlive being closed. The desktop sets mono to 19pt, up from the room's 13, a
deliberate default rather than a leftover: a terminal you read all day is worth
the size.
[Security](/docs/haus/rooms/security) brings Touch ID for `sudo`, rebuilds
included. The [theme](/docs/haus/rooms/appearance) is tuning rather than a room:
the accent the palette is built from, mauve until you say otherwise.

## What it deliberately leaves out

Coding agents (`haus.ai.enable = true` brings them here), theme ports
(`haus.theme.ports.enable`), the wallpaper, the Focus switch and the tour. Each
would reach outside the terminal, which is the one promise this desktop makes:
theme ports write theme files into apps this desktop never installed, the
desktop picture is not the shell, and a Focus switch and a tutor teach moves
this selection doesn't ship. All of them are a line in your own host file away
if you disagree.
