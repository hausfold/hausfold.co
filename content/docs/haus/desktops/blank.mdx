**Blank is a desktop that selects nothing.** It exists so that "I'll build my
own" stays inside the one-desktop model instead of becoming a second mode with
its own rules. Name it like any other, in your [`mkHaus`
call](/docs/haus/desktops/choosing#selecting-one):

```nix
desktop = haus.desktops.blank;
```

The whole file, upstream, is this:

```nix
{
  haus = { };
}
```

Everything else is the room catalogue's own neutral defaults doing the work.

## What you get

The foundation, and only that:

- **the `haus` CLI**: `rebuild`, `plan`, `diff`, `set`, `rollback`, `update`;
- **the app roster**: the one list driving what's installed and from where;
- **the Nix and rebuild plumbing**: pinned inputs, generations, garbage
  collection;
- **haus's safe macOS defaults**, nearly all of them soft, so your host outranks
  them with a plain assignment. ([Two menu-bar keys are
  not](/docs/haus/desktops/customizing#beating-a-default-haus-set), and say so.)

## What you don't

No optional room is on, and no global hotkey is claimed: Caps Lock stays Caps
Lock, ⌘Space stays Spotlight's. The wallpaper is left alone, the tour doesn't
run, and no theme files are written into apps you already had. That last one is
the point of Blank rather than a stripped hacker: nothing reaches outside haus
to change something you didn't ask for.

## Adding a room

Every room is one switch in your host file at
`~/.config/nix/hosts/<hostname>/default.nix`:

```nix
haus.bar.enable = true;      # the bar
haus.launcher.enable = true;    # the launcher
haus.keys.palette = "cmd-space";
```

```sh
haus rebuild
```

A room enabled is a room that works: each ships a neutral, useful configuration,
so the bar draws and the launcher opens with nothing tuned. Tune it from that
room's page afterwards, or leave it.

<Callout title="Rooms don't switch each other on">
Turning on the Bar doesn't bring the launcher, and Development doesn't bring
coding agents. Where two rooms cooperate (agent pills on the bar, agent commands
in the launcher) the extra appears only when *both* are on, and its absence
never disables the room that offered it.
</Callout>

## Growing out of blank

Turning on most of the catalogue means you are describing a desktop that already
exists: [select one](/docs/haus/desktops/choosing) and override the two or three
things you disagree with. If what you have is genuinely yours and you want it on
a second Mac, that's a [desktop of your own](/docs/haus/desktops/creating).
