The Launcher room installs **[pounce](/docs/pounce)**, a native command palette
where every command is a shell script in a folder. Hit **⌘Space**, fuzzy-type,
hit **Return**: apps, your own commands, clipboard history, an emoji grid and
inline answers, all in one list.

Pounce is free, MIT and installs standalone from Homebrew without any of this.
What the room adds is the wiring: the daemon as a login item, ⌘Space actually
free, and the one macOS permission surviving a rebuild.

## Enable it

```nix
haus.launcher.enable = true;
haus.keys.palette = "cmd-space";   # or alt-space, ctrl-space, "none"
```

```sh
haus rebuild
```

Only `cmd-space` displaces Spotlight; moving the palette elsewhere is how you
keep both. haus frees ⌘Space from Spotlight so pounce can own it, which is the
step a standalone install has to do by hand.

## Configure it

`config.json` is **generated** from `haus.launcher.*`, so `pounce config init`
refuses inside haus; the next rebuild would put the generated file straight
back. Change it in your host file instead, and the rebuild bounces the daemon
for you when one of the startup-only keys moves.

```nix
haus.launcher.windowSwitcher = true;          # ⌘Tab by window; defaults on here
haus.launcher.autoQuit.enable = false;        # quit an app when its last window closes
haus.launcher.items."mode:emoji".hotkey = null;   # leave Fn/Globe native
```

`haus.ui.scale` writes pounce's `scale` for you, and your `haus.theme.flavor` /
`haus.theme.contrast` reach it as a palette file, so the palette matches the
rest of the house without a second theme setting.

### The Fn/Globe key

haus binds the emoji picker to Fn, and macOS wants that key too: HIToolbox
carries its own Globe handler inside every process, below the event stream
pounce can read, so Apple's Emoji & Symbols picker can open alongside ours.
`haus.launcher.fnKey` decides how that argument is settled:

| | |
|---|---|
| `"tap"` | The default. Pounce reads Fn with an event tap and **shares** the key, so macOS may still answer it. Setting System Settings ▸ Keyboard ▸ "Press 🌐 key to" to Do Nothing helps, but the two are still racing |
| `"remap"` | Turns Fn into F19 at the HID layer, so there is no Fn key left for macOS to race. The cost is that Fn stops being Fn **everywhere**: no Fn+arrows, no Fn+Delete, no Fn+F1–F12 |

Worth `remap` on a Mac where Fn is only ever the emoji key; a bad trade where
Fn+arrows is muscle memory. Or hand the key back entirely with
`haus.launcher.items."mode:emoji".hotkey = null`. `pounce doctor` reports which
of the two is actually carrying the key.

<Callout title="Keeping the Accessibility grant">
```nix
haus.launcher.signingIdentity = "Apple Development: you@example.com (XXXXXXXXXX)";
```

A plain Nix rebuild is ad-hoc signed, and macOS ties an Accessibility grant to
a signature, so without this you re-approve the dialog after every rebuild.
Set it and the room re-signs a stable copy of the app with your identity, and
the grant persists.

It is **host-only**: it names a certificate on one machine, so a shared desktop
may not set it.
</Callout>

## Works with

- **[Apps](/docs/haus/rooms/apps)**: **Install App** writes a roster entry and
  rebuilds.
- **[AI](/docs/haus/rooms/ai)**: **Spawn Agent** creates a named worktree and
  opens a session in it.
- **[Focus](/docs/haus/rooms/focus)**: the quiet switch is a command here too,
  and every scene you declare gets a **Scene: &lt;name&gt;** row of its own.
- **[Development](/docs/haus/rooms/development)**: when a lane is a window
  (`haus.terminal.lanes.backend = "zmx"`), **Lanes** jumps to one or searches
  what the agents are saying, and **New Shell Window** is what ⌘P becomes.
- **[Windows](/docs/haus/rooms/windows)**: the opt-in `⌘Tab` window switcher,
  which groups its rows by AeroSpace workspace.

Each command appears only when its room is on.

## Remove it

```nix
haus.launcher.enable = false;
```

<Callout type="warn" title="⌘Space doesn't go back on its own">
haus disables Spotlight's shortcut with a one-way write, and nothing re-enables
it. Put it back yourself in System Settings ▸ Keyboard ▸ Keyboard Shortcuts.
</Callout>
