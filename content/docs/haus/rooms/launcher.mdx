Hit **⌘Space**, fuzzy-type, hit **Return**: apps, your own commands, clipboard
history and quick answers, every command a shell script. The palette is
[pounce](/docs/pounce); this room is its wiring.

```nix
haus.launcher.enable = true;
haus.keys.palette = "cmd-space";   # or alt-space, ctrl-space, "none"
```

Only `cmd-space` displaces Spotlight; the rest keep both. `haus permissions` has
a card for each macOS grant. Without **Automation**, Lock Screen and Force Quit
do nothing and say nothing, and a popup lands wherever Ghostty last left a
window rather than over the one you summoned it from. The Accessibility grant
survives every rebuild.

## Configure it

`config.json` is generated from `haus.launcher.*`, `haus.ui.scale`,
[`haus.fonts.sans.name`](/docs/haus/rooms/appearance#type) and your theme, so
`pounce config init` refuses inside haus. Edit your host file instead.

```nix
haus.launcher.windowSwitcher = true;      # ⌘Tab by window, on here
haus.launcher.autoQuit.enable = false;
haus.launcher.plugins = [ "docker" "tailscale" ];
```

`plugins` turns on commands that assume a tool you have: `audio`, `bluetooth`,
`caffeinate`, `docker`, `github`, `perplexity`, `spotify`, `ssh`, `tailscale`.
Naming one installs the CLI behind it: `bluetooth` brings `blueutil`. An app or
daemon stays yours to provide.

## Rows that are listed on some pages only

**New Agent Lane** (⌘⏎), **New Shell Window** (⌘N) and its `⇧` twin act on the
page you are on, so haus lists them on `T` and the `T/<repo>` lane pages, and
only where [Windows](/docs/haus/rooms/windows) is on. **Spawn Agent** and **New
Terminal Window** (⌘T) inherit nothing and stay everywhere. Hand one back:

```nix
haus.launcher.items."cmd:lane-here".workspaces = [ ];
```

Add `bundleIds` beside it, never instead: the predicates are ANDed. Both scope
the **row**, never a `hotkey`: ⌘⏎ and ⌘N work wherever Ghostty is frontmost.
`pounce doctor` says why a row is missing.

## The Fn/Globe key

Fn opens the emoji grid, and macOS wants it too. `haus.launcher.fnKey` settles
it: `"tap"` (the default) shares the key and may lose the race, `"remap"` turns
Fn into F19 and owns it, giving up Fn+arrows and Fn+Delete. haus declares the
remap, so a rebuild cannot drop it. Or hand Fn back:
`haus.launcher.items."mode:emoji".hotkey = null`.

## Copy text from screen

**⌘⇧2** crops an area and puts its text on the clipboard, offline. The first
capture asks for **Screen Recording**; without it crops come back
wallpaper-only, reading "No text found".

```nix
haus.launcher.items."cmd:copy-text".hotkey = "cmd+shift+6";   # or null
```

`haus.launcher.enable = false;` removes the room.

<Callout type="warn" title="⌘Space doesn't go back on its own">
The write is one way. Put it back in System Settings ▸ Keyboard ▸ Keyboard
Shortcuts.
</Callout>
