This room scales a screen, so the whole Mac gets bigger or smaller, apps haus
has never heard of included; `haus.ui.scale` and `haus.fonts` only resize
haus's own surfaces. An empty `haus.displays` leaves every screen as macOS has
it.

```nix
haus.displays = {
  internal.uiScale = "larger-text";   # the built-in panel
  main.uiScale = "default";           # whichever display is main
  "37D8832A-2D66-02CA-B9F7-8F30A301B230".uiScale = "more-space";   # hausdisp list prints the UUIDs
};
```

```sh
haus rebuild
```

`uiScale` is an intent, not a pixel count: `more-space`, `default`,
`slightly-larger-text`, `larger-text`, `largest-text`, each resolved against
the ladder of modes *that* screen reports. A monitor that isn't attached is
skipped with a note, not a failed rebuild. A desktop may name `internal` and
`main`; a UUID is **host-only**.

## Remove it

Delete the entry and rebuild. That stops *managing* the screen rather than
restoring it: the panel keeps its last mode, so set the position you want
explicitly.
