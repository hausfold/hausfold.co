You know the dance: drag a file, realise the window you wanted is buried under
four others, let go, dig it out, drag again. The Shelf room installs
**[perch](/docs/perch)**, which ends it: start dragging anything, flick up to
the notch, and a small shelf drops down to catch it. Pile in as much as you
like, from as many places as you like, then grab any tile and carry the whole
group to its real home in one motion.

This page is the **room**: the wiring, the one option, and what a rebuild does.
The app itself is documented in [its own tree](/docs/perch).

## Enable it

```nix
haus.shelf.enable = true;
```

```sh
haus rebuild
```

Perch is copied to `/Applications` and kept current with the rest of the house.
Standalone and in-the-house are the same app: if you already installed it with
`brew install --cask hausfold/tap/perch`, letting the room own it is the
upgrade.

The room also puts **`perch` on your PATH**, the shelf's command-line door:

```sh
perch add report.pdf shot.png
```

The tool ships inside the app, so the room links it out of the copy in
`/Applications` rather than installing a second bundle for one 419 KB binary.
[Install](/docs/perch/install#the-command-line) has why it is named
`perch-cli` in there; [Using the shelf](/docs/perch/using) has what it does.

## Configure it

Two settings. The first is about colour:

```nix
haus.shelf.followSystemAppearance = true;
```

With it on, the shelf follows macOS Light/Dark itself (no rebuild, no relaunch)
at your `haus.theme.contrast`, rather than being pinned to
`haus.theme.flavor` like every other themed tool. The shelf has no theme picker of
its own (a five-second surface has nowhere to put one), so this is the only word
on its colours.

The second is about screenshots:

```nix
haus.shelf.watchScreenshots = true;  # the default
```

Screenshots are the thing people most want the shelf to catch by itself, and
the hardest to set up — perch watches folders you hand it in a panel, and a
sandboxed app is never told where macOS saves captures. This machine knows, so
it says: the folder goes into `~/.config/perch/config.json`, and perch's
**Shelf my screenshots** switch opens its folder panel already pointed there.
One click grants it; nothing else can, because the grant *is* the click.

haus only knows the folder when it owns the setting
(`haus.screenshots.location`). Leave that unset and perch falls back to the
Desktop, which is macOS's own answer and right on most Macs.

The same option turns the floating screenshot thumbnail off
(`haus.screenshots.thumbnail`, at `mkDefault` — name it in your host to put it
back). That is not tidiness: the thumbnail *holds* your capture for about five
seconds before the file is written, so a watched folder catches every
screenshot five seconds after you took it.

## Works with

- **[the Appearance room](/docs/haus/rooms/appearance)**: the shelf takes your palette
  and contrast, unless you hand the polarity to macOS with
  `followSystemAppearance`.

## Permissions and side effects

This room grants **nothing**, because the shelf asks for nothing: no Accessibility,
no Input Monitoring, no Screen Recording, no Dock icon, no telemetry. There is
no permission step in a rebuild for it, which is unusual enough here to be
worth saying.

Two macOS settings get in the shelf's way, and the room turns both off for you
while it's enabled (disabling the room stops haus writing them, but macOS keeps
the last value written — flip them back by hand if you want them):

- **Desktop & Dock ▸ "Drag windows to top of screen to enter Mission Control"**,
  switched off outright. macOS arms that top-edge trigger for the whole of any
  drag, files included, and it fires over the same band the shelf lives in.
  Left on, the Dock steals the drop, and nothing perch can do stops it —
  which is why this one isn't a preference the room asks you about.
  [Install](/docs/perch/install) has it for a Mac without haus.
- **The screenshot preview thumbnail**, switched off as a default, and only
  while `haus.shelf.watchScreenshots` is on (see [Configure
  it](#configure-it)). macOS parks a new capture in the bottom-right corner and
  only writes the file when that thumbnail expires (about five seconds) or you
  dismiss it — so a [watched folder](/docs/perch/using) pointed at your
  screenshots catches them five seconds after you took them. This one is only a
  delay rather than a defeat, so it's a `mkDefault`:
  `haus.screenshots.thumbnail = true;` in your host puts the thumbnail (and its
  markup and drag affordances) back.

## Remove it

```nix
haus.shelf.enable = false;
```

The room stops installing and updating it. The copy already at
`/Applications/Perch.app` stays until you delete it; a rebuild never removes an
app from your Applications folder behind your back.
