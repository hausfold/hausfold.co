**Development** is the room the command line lives in. It sets up the whole command line (emulator,
session persistence, shell, prompt, file manager, editor, and a toolbelt of
modern replacements for the usual commands), painted from the same
[palette](/docs/haus/rooms/appearance), down to the default editor.

| | | |
|---|---|---|
| Terminal | [Ghostty](https://ghostty.org) | title bar hidden, kitty graphics, one window per pane |
| Sessions | [zmx](https://github.com/neurosnap/zmx) | every window's shell survives the window |
| Shell | zsh | no framework, fzf-tab, sensible history, git aliases |
| Prompt | [starship](https://starship.rs) | |
| Files | [yazi](https://yazi-rs.github.io) | markdown, code and image previews |
| Editor | [helix](https://helix-editor.com) | the default `$EDITOR`, or neovim, vim, nano ([below](#choosing-your-editor)) |
| Jumper | [zoxide](https://github.com/ajeetdsouza/zoxide) | `cd` learns your habits; `cdi` opens a picker |

Plus `bat` over `cat`, `lsd` over `ls`, `lazygit` (`lg`), `delta` for git diffs,
and `fzf`, `fd`, `jq`, `gh`, `glow`, `fastfetch`, with `nix-index` and `comma`
so you can run anything else in nixpkgs without installing it.

## Enable it

```nix
haus.developer.enable = true;
haus.developer.languages = [ "node" ];
```

The terminal stack itself (Ghostty, zmx, zsh, the prompt, the editor) is
part of the foundation and always there. `haus.developer.*` is what brings the
*tools*: the CLI toolbelt, the Git tooling and the language runtimes, each with
a sub-switch of its own (`.toolbelt`, `.git`, `.languages`).

## A window is a pane

There is no multiplexer. A "pane" is a real Ghostty window, tiled by the
[Windows](/docs/haus/rooms/windows) room, and every window's shell runs inside
its own [zmx](https://github.com/neurosnap/zmx) session — so closing a window
**detaches** it rather than ending it, and the next window Ghostty opens walks
straight back into the shell you had, scrollback and all.

That buys two things a multiplexer cost. Images render for real: a multiplexer
is a second terminal emulator in the middle of the pipe, and kitty graphics
never survived the trip, so previews were half-block art. And there is one
layout model instead of two nested ones — the same chords tile your browser and
your terminal.

Ghostty's own `⌘T`, `⌘N`, `⌘Y`, `⌘F` and friends are **unbound** on purpose, so
those keys mean here what they mean in every other app rather than what a
terminal decided. (`⌘C` is not one of them; it stayed with Ghostty, as copy. A
`⇧`-drag makes a selection over whatever TUI has taken the mouse, and `⌘C` takes
it.)

Two of them do nothing at all, on purpose:

- **`⌘T` / `⌘⇧T`.** There are no tabs — a tab would nest a second layout model
  inside one tile. `⌘N` is "a new window here", which is what `⌘⇧T` used to mean.
- **`⌘D` / `⌘⇧D`.** Ghostty's defaults there split the surface, and splits go
  unused for the same reason: the tiler already tiles. It's an easy chord to hit
  by accident coming from iTerm, so the keys do nothing rather than something
  else.

| Keys | What happens |
|---|---|
| `⌘N` / `⌘⇧N` | New shell **window**, in the focused window's directory — the same key every Mac app spells "new window". The plain one hops to the repo's **main checkout** when you're inside an agent worktree; `⇧` stays put. |
| `⌘W` | Close the window — which **detaches** its session rather than ending it. The shell keeps running; the next window claims it back. |
| `⌃D` / `exit` | End the shell — which ends its **session** and closes the window with it, on the first press. The opposite of `⌘W`: there is nothing left running to walk back into. |
| `⌘F` / `⌘⇧F` | [Find](#finding-things) in this pane / across every pane |
| `⌘G` | Your GitHub review queue, if you turned it on |
| `⌘⏎` | Spawn a coding agent in its own worktree, on the repo this window is looking at |
| `⌘Y` / `⌘⇧Y` | [yazi peek](#yazi-peek), with and without the worktree hop |
| `⌘L` | Links picker: every URL in the pane's transcript or scrollback |
| `⌥` right-click a window | Fullscreen it — zoom is the mouse's, not a chord |
| `⌃⇥` / `⌃⇧⇥` | Walk the lane pages by recency, most-recent-first, like `⌘⇥` over apps |
| `⌥/` / `⌥,` | Tiles layout / accordion layout |

**An agent worktree** is the throwaway checkout `⌘⏎` puts a coding agent in: its
own copy of the repo on its own branch, so several agents can work at once
without fighting over one set of files. Half the rows above have a `⇧` variant
because of it: the plain key assumes you want the *real* repo, and `⇧` says stay
in the copy. The [AI room](/docs/haus/rooms/ai) has the rest of the
lifecycle: resuming one, setting work aside, cleaning up.

**A lane's terminal is a window like any other**, and its own
[zmx](https://github.com/neurosnap/zmx) session — which is why `⌘⏎` is held at
the window layer rather than inside the terminal; [the AI
room](/docs/haus/rooms/ai) has that story. The session outlives every client
attached to it, so `⌘W` detaches and the agent keeps thinking, and reopening the
lane rejoins the live conversation instead of replaying a transcript. The trade
is splits: zmx has none by design, so [windows](/docs/haus/rooms/windows) tiles
real windows rather than a second window manager nested inside a terminal. That
room is worth having and is not required: with it off, lanes open as ordinary
macOS windows wherever macOS puts them, and the build says so once as a
warning. Everything else about a lane is the same — `⌘⏎` spawns one, `⌘W`
detaches, `⌘F` searches this window, and the bar's agents pill still goes to a
lane and peeks it.

Each repo's lanes tile on their own page, `T/<repo>`, so pounce work and haus
work don't pile onto one screen. `⌘N`, `⌘⏎` and `⌃⇥` are only taken while
Ghostty is frontmost, so `⌘⏎` still sends in Slack, `⌘N` still opens a new
window in your browser, and `⌃⇥` still walks that app's own tabs. The [Launcher](/docs/haus/rooms/launcher) room does that half, and
gains a **Lanes** command beside them: fuzzy over every lane with its state,
`↵` focusing that lane's window or waking a parked one, `/` plus a word
searching what the agents are *saying* across every live session.

A **Pages** command covers the pages themselves: `↵` goes to one, `⌥↵` throws
the focused window onto it and follows it there. The [bar](/docs/haus/rooms/bar)'s
`page` pill opens the same list, in move mode on a ⇧/right-click. Typing a name
no page has yet isn't a miss — the tiler makes a page on first use, so you can
throw a window onto a repo whose first lane hasn't been opened.

Every one of those chords is taken **only while Ghostty is frontmost**, so each
still means whatever it means everywhere else. They are held there rather than
by the terminal for a plain reason: Ghostty has no keybind action that runs a
command, and each of these runs one.

There is **no reload chord**, because there is nothing to reload: Ghostty
watches its own config and applies a change within a second. A `haus rebuild`
lands on the windows you already have — same directories, live agent
conversations uninterrupted.

<Callout title="Opening a link">
`⌘⇧`-click opens the link under the pointer, and `⌘⇧`-hover previews where it
goes. It is `⌘⇧` and not a plain click because most of what you'll click sits
inside a program that has taken the mouse (an agent, `lazygit`, `vim`): the
terminal's mouse protocol has no bit for `⌘`, so a plain `⌘`-click arrives at
that program indistinguishable from any other click. `⇧` is the one modifier
Ghostty always keeps for itself, which is what makes the pair dependable
anywhere.
</Callout>

## Finding things

`⌘F` opens a search overlay for the focused window, `⌘⇧F` the same overlay
across every window at once. It floats over the window that summoned it, so
`Esc` puts you straight back. Results appear as you type, with the lines around
each hit beside them. `⏎` jumps to the window a hit came from, `^y` copies the
line, `^s` flips between this-window and every-window without losing your query.

**In an agent window it searches the conversation, not the terminal.** Claude
Code and Opencode render in the alt-screen, which has no scrollback at all, so
searching the grid would only ever find what's on screen this second. Searching
the stored conversation finds all of it, including text inside collapsed tool
output. Codex falls back to scrollback; it reports its state like the others but
carries no conversation id to join to. Every other window gets its full
scrollback — the *whole* of it, since that is what the session holds.

## Your review queue

`⌘G` opens [gh-dash](https://github.com/dlvhdr/gh-dash) in a near-fullscreen
floating window, themed like everything else and gone again on `q`. It's off unless you ask:

```nix
haus.terminal.ghDash.enable = true;
haus.git.org = "your-org";     # or your own account
```

The first line gets you the tabs that are about *you*: issues you opened, ones
assigned to you, unread notifications, threads you're in. The second is what a
PR tab needs, because a PR tab is a GitHub search and a search needs a scope.
Set it and four more appear: **open**, **green** and **red** (the same queue
split by whether CI passed; together they *are* the merge decision, and a
branch still building shows in neither), and **shipped**.

Leave `haus.git.org` empty (right if you read several owners at once) and
those four simply aren't written.

## yazi peek

`⌘Y` opens a floating file browser with live previews, sized to cover the
terminal window that summoned it exactly, so it reads as that window turning
into a file browser rather than a popup landing on it. `Enter` on a file pages
it fullscreen; `Enter` on a directory opens a new window there, which makes
peek double as a browse-and-pick directory chooser. `q` or `Esc` closes it and leaves
your layout untouched.

Markdown renders through `glow`, code through `bat`, images through `chafa`.
`Y` copies a file's *contents*, not its path.

Every floating terminal haus summons wears a thin outline that follows the
window's corner curve, so a dark terminal on a dark window still has an edge:

```nix
haus.terminal.floatBorder = "accent";  # the default; also "grey", any accent name, or "off"
```

## Git aliases

Plain zsh, no framework, and a finite set of shortcuts. The names follow the
widely-used Oh-My-Zsh vocabulary where conventions agree, and deliberately skip
the ambiguous ones (`gl`, `gr`, `gs`) whose meanings differ between alias
sets. `g` itself is `git`.

| | |
|---|---|
| Add | `ga` `gaa` `gapa` |
| Branch / checkout | `gb` `gba` `gbd` `gbD` `gbm` `gco` `gcb` `gcl` `gsw` `gswc` |
| Commit | `gc` `gca` `gcam` `gcmsg` `gcn` `gcp` `gcpa` `gcpc` |
| Diff / log | `gd` `gds` `gdw` `glo` `glog` `gloga` |
| Fetch / merge | `gf` `gfa` `gfo` `gm` `gma` `gmc` `gmff` |
| Pull / push | `gpl` `gpr` `gp` `gpf` `gpsup` |
| Rebase | `grb` `grba` `grbc` `grbi` `grbs` `grt` `grv` |
| Status / stash | `gst` `gss` `gsb` `gsta` `gstl` `gstp` `gsts` |
| Tag / worktree | `gt` `gwt` `gwta` `gwtl` `gwtr` |

Add, replace or remove one per host:

```nix
haus.git.shellAliases = {
  gsync = "git pull --rebase --autostash";   # add
  gst = "git status --short --branch";       # replace
  gco = null;                                # remove
};
```

## Choosing your editor

Name one and the room installs it. `haus.terminal.editorName` takes **helix** (the
default), **neovim**, **vim** or **nano**: one choice that installs the editor,
sets your `$EDITOR`, and points every "open in an editor" action at it. Those
open in a new terminal window, which is why the list is terminal editors.

```nix
haus.terminal.editorName = "neovim";              # installed, and $EDITOR
haus.terminal.hijackFileAssociations = true;      # off by default: make it the
                                                # opener for .json, .md, .nix, …
```

helix is the one haus paints from the palette: Nebelung has a theme for it and
none for the others, so the alternatives arrive in their own default colours.

To point haus at an editor it does **not** install (a GUI one, or something
your host installs itself), set `haus.terminal.editor` instead. That one is a
shell command haus runs, so it belongs in your host file rather than in a shared
desktop, and it wins over whatever `editorName` chose:

```nix
haus.terminal.editor = "code -w";                 # points at it; installs nothing
```

## Smaller things you'll notice

- **Nothing is lost when you close a window.** Its shell keeps running in its
  session; reopen and you land back in it, scrollback intact.
- **Agent-worktree aware.** A new shell opened inside an agent worktree hops to
  the parent repo rather than starting in a throwaway checkout. `⌘⇧N` is the
  no-hop escape hatch.
- **`Ctrl Tab` really works**, which it usually doesn't on macOS: the OS eats it
  for focus navigation before any app sees it, so the chord is caught one layer
  above.

## Works with

- **[AI](/docs/haus/rooms/ai)**: with both rooms on, agent windows get their
  chords and the worktree lifecycle around them.
- **[Appearance](/docs/haus/rooms/appearance)**: the whole stack is painted
  from the same palette.
- **[Launcher](/docs/haus/rooms/launcher)**: it hosts every terminal chord in
  this page, and commands that open a terminal land in a window beside yours.

## Remove it

```nix
haus.developer.enable = false;
```

The toolchains, the Git tooling and the toolbelt go; the terminal, shell and
editor stay, because they are the floor rather than the room. Take out one piece
at a time with `haus.developer.git.enable`, `.toolbelt.enable` or an empty
`.languages`.
