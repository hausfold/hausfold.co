A Mac out of the box is somebody else's idea of a Mac. **haus** is a layer for
macOS that rebuilds it into yours: the windows, the bar, the shell, the keys,
the apps, the settings you always change by hand. One text file describes the
machine you want, and one command makes the Mac match it.

```nix
haus.theme.accent = "sapphire";  # one hue, everywhere
haus.windows.enable = true;      # tiling, Caps Lock as leader
haus.focus.enable = true;        # Do Not Disturb, one switch
haus.terminal.editorName = "neovim";

# Claude, installed, on Caps Lock + c
haus.roster.claude = { key = "c"; name = "Claude"; cask = "claude"; };
```

```sh
haus rebuild
```

Your windows tile, your terminal is themed, Claude is installed on a launcher
key, and every one of those is a line in git you can read six months later.

## Why bother

- **It survives the machine.** A new Mac, or a wiped one, is one command from
  being the old one, because the old one was text.
- **It undoes.** A failed build never activates, and a regret is
  `haus rollback`, atomic, in seconds.
- **It's one setting, not forty.** One accent reaches the bar, your wallpaper,
  the notch shelf, the tools in your terminal and the browser, down to the sites
  you name in it.
- **Nothing is buried.** Every knob is an option with a default, and `haus edit`
  opens the file that sets it.

You do **not** need to know [Nix](https://nixos.org) going in. It is what makes
this reproducible, and the installer sets it up.

## Made for agents

Everything is a file and everything is a CLI, which happens to be exactly what a
coding agent needs: "make my terminal look like yours" is a diff, a build that
refuses to activate if it's broken, and one command back if you hate it.
[Changing your Mac with an agent](/docs/haus/agent-rebuilds) is that loop.

The [AI room](/docs/haus/rooms/ai) installs your agent clients and gives every
agent its own checkout of the repo it's on, so **⌘⏎** opens an isolated lane and
five run at once without fighting over a branch. Every rebuild also writes the
family's agent skills into each client's home, to one [shared
standard](https://github.com/hausfold/workshop/blob/main/docs/agent-surface.md):
haus's own, and the `hausfold` one that sends a bug report or an idea back to
us. Your agents already know the house when they wake up in it.

## What's in the box

haus is organised into **rooms**, each a capability you turn on, off, or leave
alone. An app store stops at the app; a room wires the keys and the macOS
settings around it too. The rooms you skip cost nothing.

| Room | What it does |
|---|---|
| **[Apps](/docs/haus/rooms/apps)** | Every app, font and CLI tool, and where each installs from |
| **[Appearance](/docs/haus/rooms/appearance)** | The palette, the accent, the wallpaper, fonts, interface scale |
| **[Displays](/docs/haus/rooms/displays)** | Per-screen scaling, as an intent rather than a pixel count |
| **[Development](/docs/haus/rooms/development)** | Ghostty, zmx, zsh, the editor, the browser, Git tooling, language runtimes |
| **[Windows](/docs/haus/rooms/windows)** | Tiling, workspaces, a launcher on a tap of Caps-Lock |
| **[Bar](/docs/haus/rooms/bar)** | A status bar: workspaces, weather, media, battery, clock |
| **[Launcher](/docs/haus/rooms/launcher)** | A ⌘Space command palette where every command is a file |
| **[Shelf](/docs/haus/rooms/shelf)** | A file shelf that drops out of the notch to catch drag-drops |
| **[Notifications](/docs/haus/rooms/notifications)** | Whose banners you see: haus draws through trill, can own the bundle, and announces new mail |
| **[Focus](/docs/haus/rooms/focus)** | One quiet switch: Do Not Disturb, your status, your hooks, and scenes it can enter on its own |
| **[AI](/docs/haus/rooms/ai)** | Coding agents, each with its own checkout of the repo |
| **[Text expansion](/docs/haus/rooms/text-expansion)** | Type a short trigger, get the long thing, in any app |
| **[Security](/docs/haus/rooms/security)** | Touch ID for `sudo`, lock behaviour, firewall, secrets |

Under them is the foundation nobody switches off: the macOS defaults, the
Homebrew policy and the `haus` CLI. The [full
reference](/docs/haus/reference/options) lists every option, with its type and
default. Each piece stands alone too: take all of it, or just
the [pounce](/docs/pounce) launcher, or just the
[nebelung](https://github.com/hausfold/nebelung) colours.

## Desktops

A **desktop** is a complete setup, written down: which rooms are on, how it
looks, what it installs. A Mac runs exactly one, and disagreeing with it is one
line in your host file.

A desktop is just a file, so it travels: make your own, or run one a friend
swears by. [Choosing a desktop](/docs/haus/desktops/choosing) covers the four
that ship and how to tell them apart.

## The shape of a haus machine

Your config lives at `~/.config/nix` and it is **yours**: your name, your keys,
your app list. It imports haus and never edits it, and haus stays upstream,
pinned to an exact commit, so nothing about your machine changes until you run
`haus update`. Your identity never sits in someone else's repo, and their
improvements are never a surprise on your machine.
