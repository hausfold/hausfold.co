**nebelhaus** turns a Mac into a quiet, keyboard-first, fog-grey workstation:
arranged like a tiling Linux rig, but native to the grain of the Mac.

It is a **desktop** — one set of opinions built on
[haus](/docs/haus), the layer underneath. Run one command and the whole house
rises: tiling windows, a status bar, a themed terminal, a command palette,
Touch ID for `sudo`, and a single muted colour scheme painted across every app
you own.

> An opinionated macOS, raised in the fog.
> Silver-grey · keyboard-first · reproducible.

Grey is the point. The palette — **nebelung**, named for a cat breed the colour
of high fog — is a muted dark theme for people who find most themes too loud.
There's a light mode and a high-contrast mode if soft grey isn't what your eyes
want.

## Is this for you

Probably, if two or more of these are true:

- You like **tiling window managers**, and wish the Mac felt more like one
  without fighting it.
- You want the machine to be **restorable** — describable in git, back on a
  fresh laptop in one command.
- You want **one look** across the terminal, editor, git and browser, instead
  of a different accent colour in every app.
- You're comfortable in a terminal.

You don't need to know Nix. The installer handles it.

## What you get

| Piece | What it does |
|---|---|
| **Tiling & launcher** | Windows arrange themselves; tap Caps-Lock to launch, focus, or throw one |
| **A status bar** | Workspace pills, weather, media, battery, clock — and a light that goes red when something has stopped |
| **A themed terminal** | Ghostty + zellij + zsh, and a toolbelt that all matches |
| **⌘Space** | A command palette where every command is a file you can write |
| **Touch ID for `sudo`** | Including inside a terminal multiplexer |
| **The colours** | One palette rendered onto twenty-odd tools |

## You're never stranded

An opinionated system only works if there's always a hand to grab.

- **Forgot a key?** Tap <kbd>⇪</kbd> then <kbd>/</kbd> for a live cheatsheet
  built from your own app list.
- **Something feels off?** `haus doctor` checks everything at once and prints
  the exact command to fix each thing.
- **Made a mess?** `haus rollback`. A failed build never activated in the first
  place.
- **Want out?** The installer snapshots before it starts, backs up every
  dotfile it touches, and never deletes an app you installed. Leaving is as
  supported as arriving.

## Install it

```sh
curl -fsSL https://nebelhaus.com/init.sh | bash
```

Then the command it prints. The [install page](/docs/haus/install) walks
through exactly what happens — and how to read the script first if you'd
rather not pipe curl into bash blind.

Once it's up: [**First run**](/docs/nebelhaus/first-run).
