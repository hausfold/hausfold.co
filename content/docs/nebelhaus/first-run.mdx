The first `switch` has finished. Windows now tile themselves, the menu bar has
been replaced, your terminal opens into a themed session, ⌘Space belongs to the
palette, and `haus` is on your `PATH`.

Here's the muscle memory.

## The four moves

| Do this | And you get |
|---|---|
| **⌘Space** | The palette. Type a few letters, hit <kbd>Return</kbd>. Start here for everything. |
| **Tap ⇪, then a letter** | Launch or focus that app. <kbd>T</kbd> is the terminal, <kbd>B</kbd> the browser. |
| **Tap ⇪, then an arrow** | Move focus between tiled windows. Keep arrowing. Hold <kbd>⇧</kbd> to *move* the window instead. |
| **Tap ⇪, then a digit** | Jump to that workspace. Add <kbd>⇧</kbd> to throw the current window there. |

Tap Caps-Lock — don't hold it. It's a leader key now, not a modifier.

<Callout title="The cheatsheet is built in">
Forgot one? Tap <kbd>⇪</kbd> then <kbd>/</kbd>. It's generated from your actual
app list, so it's never out of date.
</Callout>

## Try this, in order

1. **Tap ⇪, then `T`** — the terminal opens and tiles itself.
2. **⌘Space, type `saf`, Return** — Safari launches. That's the palette.
3. **Tap ⇪, then ← / →** — focus jumps between the two windows.
4. **⌥/** — the split flips between horizontal and vertical.
5. **⌘Space, type `emoji`, Return** — the palette becomes an emoji grid. Pick
   one; it's copied.

## One permission to grant

A few palette features — auto-paste, the emoji picker — use a keyboard path
macOS gates behind Accessibility:

```sh
pounce --request-accessibility   # approve the dialog
pounce --check-accessibility     # prints true once granted
```

Everything else works without it.

## Making it yours

Your settings live in one file. Open it with:

```sh
haus edit
```

The tweaks people reach for first:

```nix
{
  # A different accent, everywhere at once
  haus.theme.accent = "sapphire";

  # A different editor
  haus.hearth.editor = "nvim";

  # An app on the launcher, with a workspace of its own
  haus.roster.slack = {
    key = "s";
    name = "Slack";
    appId = "com.tinyspeck.slackmacgap";
    cask = "slack";
  };
  haus.workspaces.S = {
    key = "s";
    icon = ":slack:";
    apps = [ "slack" ];
  };

  # Installed, but no launcher key
  haus.roster.discord = {
    name = "Discord";
    cask = "discord";
  };
}
```

Then:

```sh
haus rebuild
```

## The commands you'll actually use

| Command | What it does |
|---|---|
| `haus rebuild` | Build, then switch. Your everyday apply. |
| `haus plan` | What a rebuild *would* change — packages, settings, files. Read-only. |
| `haus update` | Pull new versions, then rebuild. |
| `haus status` | Which generation you're on, and how stale it is. |
| `haus rollback` | Back to the previous generation. |
| `haus doctor` | Health check, with the fix for anything it finds. |

That's the short list; [the `haus` reference](/docs/haus/reference/haus) has the
rest, and [Keeping it current](/docs/haus/guides/keeping-it-current) is the loop
they belong to.

<Callout title="You're never stuck">
Lost a keybinding? <kbd>⇪</kbd> <kbd>/</kbd>. Something misbehaving?
`haus doctor`. Regret a change? `haus rollback`.
</Callout>
