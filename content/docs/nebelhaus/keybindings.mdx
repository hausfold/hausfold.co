Every default binding on this desktop, grouped by where it lives. The keys are
nebelhaus's choices — the machinery is the layer's, and the guides in the
**haus** tree explain each one — but this is the page to keep open in week one.

`⌥` Option · `⌘` Command · `⌃` Control · `⇧` Shift · `⇪` Caps-Lock.

<Callout title="There's a live copy on your own machine">
Tap <kbd>⇪</kbd> then <kbd>/</kbd> for the same list generated from *your*
tables — your app roster, your window chords, your terminal keys. Use that one
when they disagree; this page describes the defaults.
</Callout>

Three options move everything below: `haus.keys.leader` (what `⇪` is),
`haus.keys.windowNav` (what `⌥` is) and `haus.keys.palette` (what opens the
launcher). Each can also be `"none"`, which removes its bindings rather than
moving them — see [rebinding](/docs/haus/guides/window-management#not-fond-of-these-keys).

## Tiling

| Keys | Action |
|---|---|
| `⌥H` `⌥J` `⌥K` `⌥L` | Focus left / down / up / right |
| `⌥/` | Tiles layout — toggles horizontal ↔ vertical |
| `⌥,` | Accordion layout |
| `⌥F` | Fullscreen |
| `⌥⇧Tab` | Move the workspace to the next monitor |
| `⌥⇧;` | Service mode |

`⌥Tab` is deliberately unbound — `⌘Tab` below answers the same question better.

## Tap ⇪ — launch mode

| Keys | Action |
|---|---|
| `<app-key>` | Launch or focus that app (`T` terminal, `B` browser by default) |
| `1`–`4` | Focus workspace 1–4 |
| `⇧1`–`⇧4` | Throw the focused window to workspace 1–4 and follow it |
| `⇧<app-key>` | Throw the focused window to that app's workspace and follow it |
| `←↓↑→` | Focus a tiled window — drops into navigate mode, where arrows repeat and `⇧`+arrow *moves* the window |
| `-` / `=` | Resize mode: shrink / grow, repeatably |
| `V` | Clipboard history |
| `E` | Emoji picker |
| `Z` | Reopen the last closed app |
| `,` | macOS System Settings |
| `` ` `` | Re-sort every window to its workspace |
| `/` | This cheatsheet, live |
| `Esc` | Out |

## ⌥⇧; — service mode

| Keys | Action |
|---|---|
| `R` | Flatten the workspace tree |
| `F` | Toggle floating ↔ tiling |
| `Backspace` | Close every window but this one |
| `⌥⇧H/J/K/L` | Join with the neighbour |
| `↑` / `↓` / `⇧↓` | Volume up / down / mute |
| `Esc` | Reload config and exit |

## Terminal

zellij boots **Locked** — its single-key submode leaders stay inert until
`Ctrl g`, so a stray keystroke can't drop you into a submode. Everything here
works regardless of the lock.

| Keys | Action |
|---|---|
| `⌘P` / `⌘⇧P` | New pane — hopping to the repo's main checkout inside an agent worktree, or staying put |
| `⌘T` / `⌘⇧T` | New tab at `$HOME` / at the focused pane's directory |
| `⌘W` | Close the focused pane, and the tab with it when it was the last one |
| `⌘F` / `⌘⇧F` | Find in this pane / across every pane |
| `⌘G` | GitHub review queue (when `haus.hearth.ghDash.enable` is on) |
| `⌘⏎` | Fullscreen the focused pane — or Ctrl-click the pane body |
| `⌘Y` / `⌘⇧Y` | yazi peek, with and without the worktree hop |
| `⌘L` | Links picker — every URL in the pane's transcript or scrollback |
| `⌘A` / `⌘⇧A` | Spawn an agent in its own worktree, beside the focused pane or in place of it |
| `⌃⌥⇧A` | Spawn an agent in **this** checkout |
| `Ctrl Tab` / `Ctrl ⇧Tab` | Tab history back / forward, most-recently-used |
| `Alt [` / `Alt ]` | Cycle layouts: grid → spiral → columns |

zellij's own in-place search is still there, for when you want matches
highlighted in the real pane: `Ctrl g` to unlock, then `s` — or `/` once you're
in scroll mode. Both exits land you back in Locked rather than Normal.

### The mouse

A plain click opens whatever underlines under the pointer — no modifier. That
holds in every pane, including one running an agent TUI that has taken the
mouse, because the terminal reads the destination out of the cells rather than
the visible text. In a pane no program is tracking the mouse, a **file path** is
clickable too: a file opens in your editor at its `:line`, a directory opens a
new tab there. Where a program *is* tracking the mouse, path-shaped text is left
to it — otherwise clicking a filename in yazi would stop selecting it.

`⌘`-click is not part of this and never could be: the mouse protocol a terminal
program speaks has no bit for command, so a `⌘`-click arrives indistinguishable
from a plain one. The escape hatch for a target resolved wrongly is `⌘⇧`-click.

## The palette — ⌘Space

| Keys | Action |
|---|---|
| `⌘Space` | Open it |
| `⌘Tab` | Most-recently-used **window** switcher, across workspaces |
| `fn` *(tapped alone)* | Emoji picker |
| type | Fuzzy-search |
| `↑` / `↓` | Move the selection |
| `⏎` | Default action |
| `⇧⏎` | Newline — the query field is multi-line |
| `⌘⏎` | Modifier action, e.g. Reveal in Finder |
| `⌥⏎` / `⌃⏎` | Alternate actions, when shown |

## What Ghostty gives up

Ghostty unbinds `⌘T`, `⌘P`, `⌘⇧P`, `⌘Y`, `⌘⇧Y`, `⌘⇧T`, `⌘F`, `⌘⇧F`, `⌘⏎`,
`⌘R`, `⌘W`, `⌘A` and `⌘⇧A` so the multiplexer owns them — the same keys work
whether or not you're multiplexed. `⌘G` joins them when the dashboard is on.

Three worth calling out:

- **`⌘C` stayed with Ghostty**, as copy. Day to day you won't press it — zellij
  copies a mouse selection the moment you release it — but a `⇧`-drag makes a
  Ghostty-level selection and `⌘C` takes it.
- **`⌘W` was also a fix.** Ghostty's default there closes the whole surface, and
  with close confirmation off, a stray `⌘W` silently took the window and the
  session in it. Now it closes one pane. `⌘⇧W` still closes the window.
- **`⌘D` and `⌘⇧D` do nothing** on purpose. Their Ghostty defaults nest a second
  terminal *inside* the one zellij is driving — invisible to the multiplexer, so
  its layout and pane keys would apply to half the window. Use `⌘P`.
