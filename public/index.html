hausfold

We rebuild the Mac.

hausfold makes the software that turns a Mac into a workspace someone actually designed. The whole desktop, set down in a single file and themed to match, plus the small native tools that live inside it.

None of it is a skin. It is the machine, rebuilt: one file you hand to a coder, a designer, or a whole floor of them, and every Mac comes up the same. Take it as it comes, or take it apart.

  • desktops, whole machines that run as they come.
  • pounce, a launcher you teach your own commands.
  • holt, parallel coding agents that never collide.
  • perch, a place for files to park on their way somewhere else.
  • nebelung, the quieter set of colours everything shares.
  • flick, your notifications without the noise. In incubator.
